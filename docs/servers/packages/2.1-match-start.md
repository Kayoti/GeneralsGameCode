# 2.1 Staging room start creates the relay session

State: todo

## Goal

Connect the pieces: pressing Start in a Servers lobby creates a relay session, hands each player its join token, and starts the match through the relay where an Online match would negotiate player to player.

## Done when

Every item applies only in Servers mode. In Online the start flow is unchanged.

- [ ] Start is unavailable with fewer than 2 human players.
- [ ] Pressing Start disables the button, sends `CREATE`, and shows "Contacting server".
- [ ] A refused or timed-out `CREATE` shows a message and leaves the lobby open with Start enabled again.
- [ ] On `CREATED` the host sends each other human player the private message in the exact format of PROTOCOL.md 5.4, then triggers the existing start signal.
- [ ] If a player joins or leaves between pressing Start and the start signal, the host closes the relay connection, re-enables Start and sends nothing.
- [ ] A member that receives the start signal sends `JOIN` with the values from its private message. With no private message for this start it shows "Could not join the match." and returns to the lobby list.
- [ ] `NAT` is not created. The match starts when `START` arrives, with the server mode flag set and the `ServerLink` handed to the networking code.
- [ ] A `REFUSE` during join returns the player to the lobby list with a message.
- [ ] This settles PROTOCOL.md V5.
- [ ] Phase 2 gate: two instances go from the Servers button to a finished match.
- [ ] Builds with the switch on and off. Lint reports no new warnings.
- [ ] Reviewed by someone other than the author.
