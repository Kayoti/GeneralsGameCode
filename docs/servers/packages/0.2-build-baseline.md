## Done when

- [ ] The unmodified client configures and builds with the `win32-vcpkg` preset, target `z_generals`, Release. The exact commands, including how `VCPKG_ROOT` was set, are written in TESTING.md under "Build the client". If the build cannot be made to work without changing game code or installing software, the package stops as `blocked` with the full error.
- [ ] `RTS_BUILD_OPTION_SERVERS` exists in `cmake/config-build.cmake`, off by default, and defines `RTS_SERVERS` on `core_config`, in the same three lines as on the `servers` branch.
- [ ] A preset `win32-vcpkg-servers` inherits `win32-vcpkg` and sets `RTS_BUILD_OPTION_SERVERS` to `ON` and `RTS_DEBUG_MULTI_INSTANCE` to `ON`. It also sets `RTS_BUILD_GENERALS` to `OFF` if that option exists.
- [ ] The client builds with the switch on and with it off. At this point both builds contain the same code.
- [ ] The Debug configuration of the `win32-vcpkg-servers` preset also builds (`--config Debug`). The one-PC phase checks use it, because a Debug client talks to the local lobby service.
- [ ] `Servers/Relay` and `Servers/Client` are taken from `servers` unchanged (`git checkout servers -- Servers`), in their own commit.
- [ ] `Servers/Client/regions.txt` then gets `tag = eu` in place of `tag = srv-eu` (PROTOCOL.md 7.1), in a second commit.
- [ ] The relay builds with its own build file and `relay_tests` pass. Commands are written in TESTING.md under "Build the relay".
- [ ] TESTING.md no longer describes the old `win32` preset. Sections that describe launch flags stay, marked "restored by package C3".
- [ ] Reviewed by someone other than the author.
