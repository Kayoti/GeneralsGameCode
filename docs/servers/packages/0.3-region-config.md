# 0.3 Region configuration format

State: partial
Branch: servers

## Goal

Define the two configuration files that describe regions: the one the game client ships with, and the one the relay reads. Regions can then be added or changed without code changes.

## Depends on

0.1

Any source code.

## Done when

- [x] Client file format documented: region number, display name, relay host and port, tag address and port.
- [x] Relay file format documented: region number, listen port, ping limit, signing key location, VPN data locations, whether the address check is on.
- [x] Rule documented for how the client picks a region from several passes, including ties and regions that refuse or do not answer.
- [x] Rule documented for how a tag is formed so that it can never collide with a real ladder.
- [ ] Example files with the EU region, and a second commented-out region to show how one is added.
- [x] The ping limit value is confirmed by the project owner (150 ms, DECISIONS D18).
