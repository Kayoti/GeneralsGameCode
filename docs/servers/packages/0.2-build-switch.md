# 0.2 Build switch and folder layout

State: todo
Branch: servers-0.2

## Goal

Add one build option that turns all Servers code on or off, and create the empty folder the relay track will own. With the option off, the build is identical to upstream.

## Depends on

None.

## Read first

- CODEMAP "Build".
- `cmake/config-build.cmake` and `cmake/config-retail.cmake`, for how existing options and their defines are declared.
- `Core/GameEngine/Source/GameClient/ClientInstance.cpp`, for how `RTS_MULTI_INSTANCE` reaches the code.

## May edit

- `cmake/` option files
- Top-level and `Core/` `CMakeLists.txt`, only to register the option and new folders
- `Servers/Relay/` (new, with a placeholder build file)
- `docs/servers/STATUS.md` ownership table, to record the final folder names and where client configuration files live

## Must not edit

Any existing `.cpp` or `.h` file.

## Done when

- [ ] A CMake option exists, off by default, that sets one preprocessor define for game code.
- [ ] The game configures and builds with the option on and with it off.
- [ ] With the option off, no new file is compiled into the game.
- [ ] `Servers/Relay/` exists and is excluded from the game build.
- [ ] The location for client configuration files (region file) is chosen.
- [ ] Folder names are recorded in STATUS.md.

## Out of scope

Any behaviour. This package adds the switch and nothing that uses it.
